---
title: Self-Hosted Configuration
---

Memoia loads service settings from `config.yaml` and supported `MEMOBASE_*`
environment overrides. `memoia_server.env.Config` is the complete field list;
unknown or retired fields are errors, not silently ignored.

```yaml
language: en
llm_style: openai
llm_base_url: https://api.openai.com/v1/
llm_api_key: YOUR-KEY
best_llm_model: gpt-6-luna
llm_reasoning_effort: high

enable_event_embedding: true
embedding_provider: openai
embedding_model: text-embedding-3-small
embedding_dim: 1536
embedding_batch_size: 64

source_max_input_tokens: 16384
source_context_window_tokens: 131072
source_output_reserve_tokens: 32768
source_input_retention_seconds: 604800
```

Project YAML supports `language`, `llm_model`, `reasoning_effort`,
`additional_user_profiles`, `overwrite_user_profiles` and `event_tags`.
Omitted project settings inherit service defaults. A Topic has a name,
description and optional Subtopics; a Subtopic accepts `name`, `description`
and `update_description`. The loop may organize Subtopics within allowed Topics.

Fact extraction reads only the current batch. It is not constrained by profile
categories, and Source has no cumulative Fact limit. Profile/Event are maintained
by the unified flush loop (30 seconds quiet, 120 seconds maximum wait), not the
retired Buffer scheduler. Completed raw input is erased in the result transaction;
unfinished input expires after seven days by default.

Removed settings include strict mode, value validation, Event theme instructions,
summary/thinking model selectors, profile truncation limits, `system_prompt`,
`llm_tab_separator`, Buffer process/scheduling thresholds and profile-cache TTL.
Remove these keys explicitly before upgrading. Existing shared configuration is
not rewritten automatically.

Environment names use `MEMOBASE_` plus the uppercase supported field name, for
example `MEMOBASE_LLM_API_KEY`. Lists/dictionaries use JSON. Errors do not print
configuration values or credentials. Redis only coordinates writes and approximate
usage; it does not cache memory or schedule flush work.
