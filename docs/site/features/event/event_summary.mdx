---
title: Derived Event Stories
---

Events organize related supported Facts into a story. The unified AgentLoop
maintains Profiles and Events after a fixed set of Blobs is flushed. A successful
Fact import does not imply Event maintenance has completed.

An Event can contain title, summary, keywords, time, location and content.
Unknown details stay empty. Optional interpretation is separately labeled and
cannot support a Fact or Profile. Similar people or keywords alone do not mean
two occurrences are the same story.

Facts and Events have a many-to-many relation. Deleting an Event removes its
derived index, not the Facts. Message deletion updates Fact evidence immediately;
old Event text may remain until the flush succeeds, but invalid evidence is not
returned as current support.

The former `event_theme_requirement` setting and summary-first extraction chain
are removed. Supplying retired settings is an error. Inspect the original flush
Operation for failure or explicit recovery; do not re-import messages to repair
a derived Event.
