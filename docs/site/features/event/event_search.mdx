---
title: Searching Facts and Events
---

Memoia searches evidence-backed Facts directly. A Fact remains searchable before
its Event is generated and after an Event is deleted.

Send `POST /api/users/{user_id}/search` with a JSON body:

```json
{
  "query": "Why was the hiking trip cancelled?",
  "max_token_size": 4000,
  "exclude_fact_ids": [],
  "exclude_event_ids": [],
  "exclude_profile_ids": []
}
```

The response has three independent arrays: `facts`, `events`, and `profiles`.
Vector and text matches rank Facts; associated stories and profiles share the
remaining response budget. Entries are returned whole, including their evidence.
Set `include_events: false` to omit stories. ID exclusions remain strict even
when an item's content has changed.

For independent searches, use `facts/query`, `events/query`, or `profiles/query`
under the same user path. Their contracts come from the server OpenAPI document
and the maintained `@jianify/memoia` TypeScript SDK.

The old Gist API, storage and indexing paths have been removed. Legacy Event
bodies remain readable; unsupported Gist-only details are not converted to Facts.
