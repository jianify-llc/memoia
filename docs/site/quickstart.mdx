---
title: Quickstart
---

Use the fixed `@jianify/memoia` TypeScript SDK described in the repository SDK README. Provide a service origin and project Bearer key through protected runtime configuration.

Import full timestamped messages with caller source_id and stable idempotency_key. Query the original operation after unknown acknowledgement; never replay bodies blindly. Read profiles independently and use POST search/context queries. Delete source messages to withdraw their evidence; DELETE user permanently forgets that identity. There is no insert/flush pair or version alias.

See the current OpenAPI reference for exact request and response schemas. Historical deployment/data migration records do not describe the current wire contract.
