---
title: API contract
---

All current endpoints live under `/api`. Health is public; all other calls require project Bearer authentication with read/write/admin scopes. Search and event context use POST JSON bodies with read scope. Success is a typed JSON object; errors use real HTTP status and controlled detail. Source import, operation recovery, message withdrawal, permanent forgetting and management share the same contract.

The generated `openapi.json` is the exact schema. No compatibility version routes, legacy envelope or standalone buffer/flush endpoint is exposed. Historical stored data and old source identities remain readable.
