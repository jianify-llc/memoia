---
title: API Reference
---

The checked-in `openapi.json` is the public contract and the input to SDK type/validator generation. The API uses authenticated, unversioned `/api` paths. Use the repository's `docs/api.md` for evidence, time, deletion, correction, recovery and retrieval semantics.

- Messages: import fixed Blobs, read Sources and delete a Source's message contributions.
- Memory: independently query Facts, Events and Profiles; search returns all three fields.
- Corrections: update or delete an existing Fact with stable operation identity and revision checks.
- Recovery: read the original Operation, retry an explicitly recoverable original operation, inspect maintenance and flush completed changes.
- Administration: users, permanent forgetting, projects, keys, configuration, usage and profile/history management.

SDK validation, HTTP success and a deployment receipt do not establish semantic model quality or completed maintenance. Inspect the corresponding Operation and maintenance result.
